# 📺 iptv-m3u-validator

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Performance: Multithreaded](https://img.shields.io/badge/Concurrency-ThreadPool-brightgreen.svg)](https://github.com/MobileConduit)

A high-speed concurrent validator for IPTV `M3U` and `M3U8` playlists. Rapidly tests streaming server endpoints, discards dead links, and exports clean playlists for media servers and IPTV clients.

## 🚀 Run
```bash
python validator.py --input channels.m3u --output live_clean.m3u --threads 30
```
